# Smart-Drowsiness-System-with-Q-Learning
This project presents an adaptive real-time driver drowsiness detection system that combines computer vision, facial landmark analysis, Analytic Hierarchy Process (AHP), and Q-learning to detect and assess different behavioral indicators of driver fatigue. The system processes a live video stream and extracts facial features associated with drowsiness, including eye closure, blinking, yawning, and head movement.

Facial detection and landmark tracking are implemented using OpenCV and Dlib's 68-point facial landmark model. The Eye Opening Ratio (EOR) is calculated from eye landmarks to identify prolonged eye closure and detect blinks. The system uses an initial calibration process to determine an individual eye-opening baseline and dynamically calculate the EOR threshold. Blink detection is performed using consecutive frames to reduce false detections. Yawning is detected by calculating the distance between the upper and lower lip regions, with a dynamic threshold established through an initial calibration process.

Head movement is incorporated through estimation of pitch, roll, and yaw using facial landmark positions. A reference head position is dynamically calibrated, and Exponential Moving Average (EMA) smoothing is applied to the measured head-pose variations to reduce fluctuations and improve stability.

A key component of the system is the integration of AHP with Q-learning. AHP is used to determine the initial relative importance and weights of the selected facial and behavioral features, providing a structured multi-criteria weighting mechanism. These AHP-derived weights are then incorporated into the adaptive Q-learning framework. Q-learning evaluates the detected drowsiness states using an epsilon-greedy strategy and updates the weighting and decision mechanism according to the defined reward structure. This enables the contribution of different drowsiness indicators to be adaptively refined rather than relying solely on fixed thresholds.

The resulting feature contributions are combined to generate a normalized drowsiness score ranging from 0 to 1. Based on this score, the system classifies drowsiness into Low, Moderate, and High levels. When the detected drowsiness exceeds predefined levels, the system activates an audio alert. For high-level drowsiness, it can additionally send a WhatsApp notification containing IP-based location information.

The project demonstrates the integration of real-time computer vision, multi-criteria decision-making, reinforcement learning, signal processing, and embedded camera streaming into an adaptive driver-monitoring system.
